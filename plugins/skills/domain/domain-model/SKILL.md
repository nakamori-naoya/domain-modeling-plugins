# assign-domain-model（索引の語を、契約つきの要素へ割り当てる）

**このスキルは業務知識を足さない。** 正本と索引にあるものを、要素・境界・操作の契約へ写すところまでを担う。

**空欄を残さない。** 要素ごとの項目と操作の欄は、該当が無ければ「なし」と書く。空欄は、調べた結果の不存在なのか見落としなのかを区別できない。

## 0. プラグイン root を決める

<!-- BEGIN shared:skill-entry/root-block -->
```bash
BUNDLE_ROOT="${CLAUDE_PLUGIN_ROOT:-/absolute/path/to/this/plugin}"
if [ -d "${BUNDLE_ROOT}/skills/domain/domain-model" ]; then
  PLUGIN_ROOT="${BUNDLE_ROOT}/skills/domain/domain-model"
else
  PLUGIN_ROOT="${BUNDLE_ROOT}"
fi
```

`PLUGIN_ROOT`は配布物rootの絶対パスである。単一skill pluginではこの`SKILL.md`があるdirectory、複数skill pluginでは`skills/<skill>/`の2つ上に当たる。Claude Codeでは`${CLAUDE_PLUGIN_ROOT}`が自動展開される。
<!-- END shared:skill-entry/root-block -->

## 1. 置き場と規律を解決する

<!-- BEGIN shared:skill-entry/config-load -->
```bash
CFG_FILE=$(bash "${PLUGIN_ROOT}/scripts/prepare.sh" "$(pwd)") || exit 2
printf '%s\n' "$CFG_FILE"
```

**このコマンドは説明例ではない。必ず実行する。** 解決済みYAMLが空なら先へ進まない。設定ファイルを直接読んで代用しない。

本文中の `${...}` は解決済みYAMLのプロパティである。使用時に `yq -er` で読み、欠落または `null` なら停止する。
<!-- END shared:skill-entry/config-load -->

`${.instructions.assignment.directive}`に従う。

## 2. 入力を確かめる

受け取るのは次の3つである。どれかが無ければ推測せず、無いものを名指しして停止する。

| 入力 | 何か | 無いときの返し |
|---|---|---|
| 根拠づけられた入力 | 正本の絶対path、確かめた決定、未決 | 「正本のpathと決定・未決が束ねられていない」 |
| 索引 | 正本から抜き出した業務用語・業務イベント・概念・常に守られること・状態・誰が行えるか・業務ルール・拒む理由・BDD番号・未決 | 「索引が無い。正本の索引化を先に行う」 |
| 契約 | 節の一覧、種別の一覧、要素ごとの項目、操作の欄 | 「契約が渡されていない」 |

索引の`vocabulary`にある語が、要素の名前になれる語である。正本の本文を読み、索引の各語がどの節でどう使われているかを確かめてから割り当てる。

## 3. 割り当てる

`${.mapping}`、`${.disciplines}`、`${.element_questions}`を必ず読む。**読まずに割り当てると、正本に無い語を要素にするか、形が同じ語を1つにまとめる。**

順序は次のとおりで、入れ替えない。

1. **要素一覧を決める。** 索引の業務用語・概念・状態を持つものから、値オブジェクト／エンティティ／集約ルートを決める。判定は`${.mapping}`の「同一性か、値か」と「識別子だけでは集約にならない」。識別子を持っていても、その文脈でライフサイクルを扱わず、他の事実から決め直せるものは、導出される値オブジェクトにする。業務イベントのうち、この文脈の集約の操作が発するものはすべてドメインイベントにする（判断を始めるかどうかで絞らない）。イベントは通知であって事実の置き場ではない
2. **各要素の詳細を書く。** `${.element_questions}`の問いに、要素ごとに答える。要素ごとに `###`、項目ごとに `####`、操作ごとに `#### 操作: <操作名>` を置き、表にしない。不変条件は「常に守られること」から、事前条件と拒む理由は「業務ルール」「誰が行えるか」「拒むときの理由」から、正本の語のまま写す
3. **モデル図を描く。** 集約ごとに `### 集約: <集約名>` を置き、直下に `- 責務:`（一文）と `- 境界:`（この内側で1つの操作として一貫させる不変条件＝境界をここに引く理由）を書いてから、Mermaid の classDiagram を1枚描く。図にはルート・内側の要素・その集約が発するドメインイベントを描き、参照する他の集約は `<<外部の集約>>` で描く。メソッドは**公開コマンド（状態を変える操作と生成）だけ**。フィールド・ゲッター・判定だけの操作は描かない。集約の内側は `*--`、集約をまたぐ参照は `..>` にラベル（識別子か値か）、発するイベントは `..>` に「発する」。集約が2つ以上なら、末尾に `### 集約どうしの関係` の図を1枚置く（集約を1クラスずつ、識別子の参照とイベントが始める判断を矢印に）
4. **集約の境界を引く。** 複数要素にまたがる不変条件を、どの集約が守るかで決める。どの集約でも守れないものは「集約をまたぐ不変条件」に守る場所を書く
5. **状態と型の分割を書く。** 状態を持つ要素ごとに、各状態でできる操作・できない操作を並べ、型を分けるかを理由付きで決める
6. **BDDとの対応表を作る。** 索引の全BDD番号について、どの要素のどの操作と不変条件で成立するかを書く。対応しないBDDと、対応のない要素・操作を必ず1行ずつ書く（無ければ「なし」）
7. **余りを落とす。** 対応のない要素・操作を「各要素の詳細」から外し、「捨てた割り当て」へ理由付きで移す（`${.disciplines}`の規律6）
8. **捨てた割り当てと未決を書く。** 候補にして採らなかった案、根拠づけられた入力の未決、正本の未決のうちモデルに影響するものを書く

決定として渡されたことは、そのまま従う。未決として渡されたことは、関係する要素を確定に見せず、未決の節へ書く。**決定にも未決にも無く、正本からも決まらない割り当てが見つかったら、勝手に決めずに停止し、その論点を返す。**

## 4. 検査して保存する

`## 目的と範囲` `## 要素一覧` `## モデル図` `## 各要素の詳細` `## 集約の境界` `## 状態と型の分割` `## ドメインイベント` `## BDDとの対応` `## 捨てた割り当て` `## 未決` `## この資料に書かないもの`を、この順で持つMarkdownを作る。

要素一覧は`| 要素 | 種別 | 正本の語 | 目的（一文） |`の表、モデル図は集約ごとの`### 集約: <集約名>`（`- 責務:` `- 境界:` と```` ```mermaid ````の`classDiagram`）と、集約が2つ以上なら`### 集約どうしの関係`、各要素の詳細は要素ごとの`### <要素名>`の下に`#### 目的` `#### 何でないか` `#### 持つもの` `#### 不変条件` `#### 生成の条件` `#### 協働相手`と、操作ごとの`#### 操作: <操作名>`（箇条書きで 事前条件・事後条件・拒む理由・発するイベント）を置く。BDDとの対応は`| BDD | 要素 | 操作 | 成立を決める不変条件・事前条件 |`の表と、`- 対応しないBDD:`、`- 対応のない要素・操作:`の2行を置く。

型名、クラス構文、`getter`／`setter`／`repository`、テーブル、API、画面の語を書かない。

```bash
python3 "${PLUGIN_ROOT}/scripts/artifact.py" write --config "$CFG_FILE" \
  --topic <正本のファイル名から拡張子を除いたもの> --body-file <本文ファイル>
```

同じ題材の候補が既にあれば止まる。更新の依頼のときだけ`--force`を付ける。

## 5. 報告する

保存先、要素一覧（要素名・種別）、集約の境界、状態ごとにできる操作とできない操作、捨てた割り当て、未決、索引に無いが正本の本文に現れる語を使った要素（あれば）を報告する。

**停止したときは、どの割り当てが決まらなかったか、何が分かれば決まるかを返す。** 部分的な候補を保存して完了にしない。

## 実行設定の寿命

prepareが返した絶対pathを実行記録へ保持する。別shellではそのpathを`CFG_FILE`へ明示して読み、shell変数の継承を前提にしない。完了時と失敗停止時のどちらも、最後の設定利用後に`python3 "${PLUGIN_ROOT}/scripts/run-config.py" cleanup --config "$CFG_FILE"`を実行する。他runの設定やdirectoryを削除しない。
